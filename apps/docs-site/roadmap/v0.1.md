# v0.1 - Initial Release

**Status:** Released ✅

## Features

### Core

- Create, edit, delete notes
- Archive and restore
- Duplicate notes
- Markdown-first editing

### Editor

- CodeMirror 6
- Syntax highlighting
- Code block support
- Auto-save

### Organization

- Note list sidebar
- Search (title + content)
- Tags (extracted from #hashtags)
- Sort by date or title

### Data Management

- SQLite storage
- Automatic backups
- Export to Markdown + JSON
- Import from Obsidian/Markdown

### Infrastructure

- macOS, Windows, Linux builds
- Code signing (macOS)
- Notarization (macOS)
- Auto-updates

## Known Limitations

- Dark mode only
- No image support
- No sync
- Basic search (no FTS)
