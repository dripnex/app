# Dripnex — Brand Contract

> Internal document. Not for publication. Consult before every decision.

**Identity:** Dripnex is the hackable AI note taker. SQLite is the store. `.md` is export. AuthGate is first. `init.js` / `styles.css` / satellite packs are the hack.

Do not badge it “AI-powered.” Do not say notes remain files.

---

## Anti-values (what Dripnex is NOT)

Dripnex is not:

- Aspirational
- Energetic
- "Productive"
- "Intelligent"
- "Fast"
- "Futuristic"
- "AI-powered" (hype badge — the product still is an AI note taker)
- "An ecosystem"
- A files-first Markdown editor

If something visual or verbal communicates any of these — it's wrong, even if it's "nice".

---

## Personality (tension pairs)

| Axis                  | Dripnex chooses |
| --------------------- | --------------- |
| Quietude vs Energy    | Quietude        |
| Caution vs Ambition   | Caution         |
| Humility vs Bravado   | Humility        |
| Clarity vs Persuasion | Clarity         |
| Permanence vs Trend   | Permanence      |

**Rule:** If something "grabs attention", it's probably wrong.

---

## Brand Contract

1. We explain decisions, not features
2. We prefer being boring over being clever
3. We optimize for long-term trust, not short-term conversion
4. SQLite is identity. Markdown is export. AuthGate is first.
5. If a choice adds dependency, we don't make it

---

## Writing Rules

**Allowed:**

- Short sentences
- Clear statements
- Consequences
- Explicit trade-offs

**Forbidden:**

- Exclamations
- Promises
- Urgency
- Aggressive comparisons
- Inflated adjectives
- “No account to open a file”
- “Your notes remain files”
- Manifesto lines about shipping less

**Test:** If a sentence could appear in a pitch deck, delete it.

---

## Typography Rules

- Sans-serif, neutral
- Nothing geometric extreme
- Nothing display
- Nothing experimental

**Test:** If the font "speaks", it's wrong. Dripnex whispers.

---

## Color System (light mode)

```css
--bg: #fafaf9; /* off-white, not pure white */
--text-primary: #1c1c1c; /* soft black */
--text-secondary: #555555; /* editorial gray */
--border: #e5e5e5; /* silent lines */
--accent: #6b7280; /* muted blue-gray */
```

**Rules:**

- No gradients
- No SaaS blue
- No success green
- No AI purple
- No vibrant colors
- Maximum 1 accent

**Test:** If the color "stands out", it's wrong.

---

## Hierarchy Without Color

Use only:

- Text size
- Font weight
- Space
- Vertical rhythm

Color only underlines. It doesn't direct.

---

## Spacing Philosophy

"Never rush the reader."

- Generous margins
- Separated sections
- Breathable line height

Space communicates respect for the user's time.

---

## Success Criteria

The site is correct when:

- [ ] It feels calm
- [ ] It could look the same in 2035
- [ ] It could be printed without losing meaning
- [ ] It doesn't scream "startup"

---

## Decision Filter

Before any design or copy decision, ask:

1. Does this add dependency?
2. Does this grab attention?
3. Could this appear in a pitch deck?
4. Does this communicate energy or ambition?
5. Does this say notes are files, or that no account is needed?

If yes to any → don't do it.
