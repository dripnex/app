The desktop is now scriptable the way a hackable editor should be — without
waiting for a marketplace. Open a file, write six lines, see it in the
Plugins menu. The editor caught up with that surface: lists, line commands,
a palette that jumps, and chrome that does not fight the window.

## Editor

- **Slash commands.** Type `/` for headings, lists, fences, and GitHub
  alerts (`note`, `tip`, `important`, `warning`, `caution`).
- **Fence languages.** After a fenced code opener, pick `ts`, `python`, `mermaid`…
  Fences can show a filename and line numbers. Put the cursor in a fence
  and **Copy** appears; preview does the same on hover.
- **Selection toolbar.** Bold, italic, highlight (`<mark>`), GitHub alerts,
  and **Edit with AI** on the selection — not a ribbon.
- **Lists.** Tab and Shift-Tab indent by the marker (`-` is two spaces,
  `10.` is four). Enter continues a list, task, or quote; an empty item
  outdents. Checked tasks (`- [x]`) strike through in the source and in
  preview.
- **Line commands.** Join, sort, case, find the word under the cursor,
  split the selection by line, scroll and center. Same muscle memory the
  v6 editor shipped.
- **Links.** Hover `[label](url)` or `<https://…>` to see the destination.
- **Readable line length.** Settings → Editor. Caps the source and
  preview at a comfortable column. Off by default.
- **Outline.** `#` in the header. Headings on the right. Click to jump.
- **Paste as Link** (`⌘⇧K`) wraps the selection with the URL on your
  clipboard. Pasting a URL into the editor also wraps a selection, or
  offers Title / Link / `<url>` instead of silently rewriting.
- **Tables.** Edit with Tab / Shift-Tab. Commands in the palette
  (`Table: …`). The parser lives in `@dripnex/tables`.
- **Export.** HTML, PDF, and print from the Note menu.

## Command palette

One palette. Type to filter. Prefixes jump:

- `>` commands
- `b ` notebooks
- `t ` tags
- `#` headings

Matching is fuzzy (subsequence), not a strict substring. Escape clears
the prefix, then closes.

## Wikilinks

- `[[Note]]`, `[[Note#Heading]]`, and `[[#Heading]]` on the current note.
- Cmd-click a link in the editor. Click it in preview.
- Missing notes are marked; follow one to create and open it.
- Hover peeks the target. Autocomplete offers titles and headings.
- Copy note link includes the heading hash when you are on one.
- `dripnex://note/…`, `dripnex://notebook/…`, `dripnex://tag/…` open from
  the OS and from preview.

## Notebooks and chrome

- Each notebook can have its own Lucide icon.
- Click a notebook to focus that tree. Escape or the breadcrumb home
  returns to All Notes. Inside a workspace the All Notes row hides —
  the tree already scopes the list. Collapsed notebooks list descendant
  notes.
- Default notebook (Settings → General) is used for ⌘N from All Notes.
- Back, forward, and distraction-free live in the editor chrome.
- Header rows (sidebar, note list, editor) sit on the same 44px line as
  the traffic lights.
- Conflicts are one screen: keep this device, keep the other, or open both.
- Sync says so when there is no encryption key. Set up is in the footer.

## Themes

- **Parchment, Wave, Night, Glass.** Official token palettes live on
  Settings → Themes. Glass lets the desktop show through the chrome
  (macOS vibrancy, Windows acrylic; Linux stays opaque). Performance →
  Low drops the blur. Look at the main window — and Settings, which is
  now the same material.
- **Vim** is a community plugin (`dripnex/plugin-vim`), not a built-in.
- Appearance keeps zoom, accent, and effects. Named palettes moved off
  that page.
- A community theme is the same contract in its own repo, loaded as a
  plugin. `dripnex.themes` is the API.

## Settings

- **Plugins** nests Installed, Install, and Updates. Updates compare the
  registry version to the one on disk — not a store.
- **Keybindings** is its own page. The table is the live map; save
  `keybindings.json` to override.
- Switches, selects, and numbers share one row component so every page
  lines up.

## Edit with AI

- **Inline.** Select text, `⌘↩` (or the pen on the toolbar). Type an
  instruction or pick a preset. The result replaces the selection — the
  AI panel stays closed.
- **Next edit.** Ghost text at the cursor. Manual (`⌥\`) by default;
  automatic after a pause; or off. Tab accepts, Escape dismisses.
  Settings → AI. Prompts are not logged.

## Yours to script

- **init.js** runs on load. Free-form `dripnex.*` or a full plugin manifest.
- **styles.css** restyles any corner. Save, it applies. Scope rules to a
  notebook with `[data-notebook-id="…"]`.
- **keybindings.json** remaps any command. `null` unbinds a default.
  Contexts: `editor`, `note-list` (`j`/`k`), `app`, `global`.
- **Insert Date** (`⌘⇧D`) ships in the default init script.

Open them from **Plugins → Open Init Script / Stylesheet / Keymap**, or
from the command palette. Reload plugins with `⌥⌘R`.

## Plugins

A community plugin is **its own git repository**. Version is the git tag.
The artifact is the tarball from `dripnex-plugin pack` on that GitHub
release.

```bash
dripnex-plugin install acme/mermaid-plus
dripnex-plugin install acme/mermaid-plus@v1.2.3
```

Or Settings → Plugins → Install, same spec. There is no in-app store yet.

The package can ship `keymaps/*.json`, `menus/*.json`, and `styles/*.css`.
They load while the plugin is enabled.

From `init.js` or a plugin:

- `dripnex.components` — Button, Modal, Dialog
- `dripnex.markdownRenderer` — remark / rehype / React / code components
- `dripnex.editor.getView()` / `dripnex.getActiveEditor().cm` — the live
  CodeMirror 6 view
- `dripnex.themes` — register and switch palettes
- Notes, notebooks, and tags can be written; the UI refreshes

Built-ins stay in the desktop until they earn their own repo. Proof
plugins (word count, typewriter) stay off the public list.

## Templates

Meeting, Decision, Daily, Weekly, Reading, Issue live in the Templates
notebook. New from template is the stack icon on the note list.
Frontmatter `instruction:` is for Ask Notes / MCP.

## Knowledge and GitHub

- The graph is a knowledge map: kinds, inferred edges, inspect vs open.
- Connect GitHub, import an issue into Inbox, ask notes about issues.
- Push a git notebook to a GitHub remote. Pull into SQLite is still later.
- Local HTTP (Settings → Integrations) speaks books, tags, notes, and a
  durable `_changes` log. Attachments are not in this release.

## Development Mode

Settings → General. Right-click → Inspect Element. The same loop a
hackable editor uses to tweak CSS.

## Coming from earlier builds

`init.js` / `styles.css` / `keybindings.json` are created on first launch
in the data directory. They are yours — Dripnex will not overwrite them.

What’s New is this file. `CHANGELOG.md` is the engineering log. Promotion
PRs are titled `chore(release): promote X.Y.Z` so the story is not a
commit dump.
