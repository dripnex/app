Settings → Themes → Install used to download the pack and then quit the
app. The palette was on disk after you relaunched; the window was gone.
This build keeps you in the app. Limestone (or any first-party pack) can
move to In use on that same page.

Settings also has Hack now — init.js, styles.css, and the keymap on one
list instead of hunting Plugins.

## Themes

- **Install stays open.** Pick a pack on Settings → Themes, click
  Install. The window does not quit. The new palette can show as In use
  without a relaunch.

## Hack

- **Settings → Hack.** Open init.js, styles.css, and the keymap from one
  page. These files live in the data directory. Save to apply.
- **Make this sendable.** A first-write init.js registers an AI command
  that turns messy notes into a document a person would send — not a
  model dump. Existing init.js files are not overwritten.
