Restart to Update tells you when the disk is full instead of vanishing.
Every tag chip on a note can be removed.

## Updates

- **Disk full.** If there is not enough space to unpack the download,
  Settings and the banner say so. The window stays open.
- **Restart.** Failed installs no longer destroy every window first.

## Editor

- **Tags.** The × on a chip works for `#tags` in the note and for tags
  you added in the header. Content tags are stripped from the markdown.
  The row wraps so the control is not clipped.
