Dripnex has always let other agents read and write your notes through its
own MCP server. Now it works the other way too: point your chat at an MCP
server you run locally — Linear, Slack, your own script — and it gets new
tools, with the same confirmation step every write already asks for.

## AI

- **Connect MCP servers.** Settings → Integrations → Connect MCP servers
  lists what's configured, shows whether each one is connected, and lets
  you add one by command and arguments. Its tools show up in chat
  namespaced to its server, and every call still needs your confirmation —
  there's no auto-exec path for a server you didn't vet yourself.
- **A native prompt before anything new runs.** Adding or changing a
  server's launch command shows a system confirmation dialog before it's
  saved and allowed to run, so a compromised plugin can't quietly add a
  process that launches on every startup.

## Motion

- **Sidebar rows.** Hover and press get a GSAP tween — short, quiet, off
  when you asked for less motion.
- **AI panel.** Opening the AI aside plays the same panel-in motion as the
  rest of the chrome.

## Editor

- **Tag chips.** The × on a chip now removes `#tags` written in the note
  body, not just tags added from the header.

## Reliability

- **Disk full.** If there isn't enough space to unpack an update, Settings
  and the banner say so instead of the window just vanishing. A failed
  install no longer closes every window first.
- **Plugin catalog.** The public plugin catalog keeps serving its last-known
  list if the GitHub auth it uses to refresh is down, instead of going
  empty.

## Security

- Patched transitive dependency advisories in Next.js, sharp, DOMPurify, and
  smol-toml.
