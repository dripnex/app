The workspace opens without an account. Sign in only when you want
end-to-end cloud sync.

## Workspace

- **Your notes open first.** A first launch shows the welcome, then the
  workspace. The next launch opens on your notes. An account is not
  required for either.
- **Sign in where sync lives.** Settings → Account, and Enable Sync, are
  where you sign in. Signing out keeps the notes on this computer and
  stops sync.

## Sync

- **A delete reaches your other devices.** Trashing a note is marked to
  sync, so the other computers drop it too.
- **A conflict copy is not pushed when it is created.** The copy kept on
  this computer stays here until you edit it. An edit syncs like any
  other note.
- **Two computers compare the version they actually received.** A push no
  longer skips changes from another device, so the same conflict does not
  return on the next sync.
- **The status names why sync stopped.** You see whether the session
  expired, you are offline, or sync still needs to be set up.
