# Dripnex desktop — UX quality research

Written 2026-08-28 against `develop` after v0.19.x. Desktop only.

## What the product is

Markdown-first, offline-forever notes. Raycast command palette + Obsidian wikilinks + a small plugin API. Chrome is token-driven (`tokens.css`). Named palettes are **satellite packs**, not bundled in core (`OFFICIAL_THEMES = []`).

Competitors people actually switch from: Obsidian, Inkdrop, iA Writer, Bear, Linear (for chrome feel), VS Code (for editor keymap).

## Quality bar (what still feels unfinished)

| Surface         | Today                                                                                         | Next                                                                                                                                                 |
| --------------- | --------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| Motion          | CSS token scale plugin. Toasts/palette are CSS keyframes. No event choreography.              | GSAP runtime: enter/exit for toast, palette, AI panel. Honor `prefers-reduced-motion` and Performance → Low.                                         |
| Themes          | Catalog of GitHub `theme-*` packs. Empty picker until install.                                | Ship a built-in **Palette Library** plugin (registerTheme) so Appearance is not empty on first launch, without reversing the satellite architecture. |
| Editor GFM      | Preview tasks, no source-mode toggle. Footnotes render, no insert. CSV fences are plain code. | Built-in plugins: footnotes, task toggle, CSV/TSV table preview.                                                                                     |
| PKM loop        | Graph exists. No daily note, random note, backlinks list, related-by-tag.                     | Commands + sidebar widgets.                                                                                                                          |
| GitHub          | Connect / import / watch works. Last-pulled is raw ISO. Empty watch list is blank.            | Relative time, empty copy, Enter to import, toast on success.                                                                                        |
| 1Password       | Account remember + encryption handoff.                                                        | Toast on remember; copy that says what happens next.                                                                                                 |
| Visual language | “If it grabs attention it is probably wrong.”                                                 | GSAP durations 120–220ms, 6–10px travel, `power2.out`. No bounce, no theme flash.                                                                    |

## GSAP decision

GSAP 3 is free (Webflow acquisition). Use **core only** (no ScrollTrigger). Canonical reduced-motion: skip tweens and `gsap.set` end state. Performance Low = same as reduced motion. The existing Motion plugin’s `scale` config becomes `gsap.globalTimeline.timeScale`.

Event names: `toast-in`, `toast-out`, `palette-in`, `panel-in`. Plugins may `require('gsap')` from the host whitelist.
